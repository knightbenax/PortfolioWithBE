# COMP229 React Portfolio — Assignment 1

A six-page React portfolio website created for COMP229 Web Application Development.

## Pages

- Home
- About Me
- Projects
- Education
- Services
- Contact Me

## Assignment requirements covered

- React-based portfolio
- Navigation between all six pages
- Custom RA logo
- Home welcome message and mission statement
- About Me page with name, profile image and resume link
- Three project entries with project visuals, role and outcome
- Education / professional qualification section
- Services section
- Contact information panel
- Interactive contact form
- Form captures required fields and provides a route back to Home
- Responsive CSS
- Contextual variable and component names
- Comments/documentation can be expanded as needed

## Run locally

```bash
npm install
npm run dev
```

Then open the local URL shown by Vite.

## Build

```bash
npm run build
npm run preview
```
